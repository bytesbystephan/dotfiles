# dotfiles

Here you can find my personal collection of scripts and configurations.

For many years, I was portying and copying my little scripts from machine to machine. I decided it was about time to put everything in order and create a proper place to store and manage everything.

Feel free to fork this repository and adjust the configurations to your own needs

## install

> Warning: Bootstrap this project only after you've reviewed the files and agreed to apply them to your system.

These dotfiles are used on macOs and debian based distributives.

To roll out these configurations on your machine, simply run the following command:

```bash
git clone https://github.com/bytesbystephan/dotfiles.git
cd dotfiles && ./install.sh
```
